[Dealership CRM Regression] Shipment navigation tab reset causes paperwork line-item totals desync during active chat filter

Preconditions

1. User is authenticated as Sales_Manager.
2. Deal record #D-9482 has generated paperwork and active shipment carrier dispatch.

Steps to Reproduce

  1. Navigate to Deals → Active Pipeline and open Deal record #D-9482.
  2. Apply the chat filter Unread AI Follow-Up in the side drawer.
  3. Click the Shipment Navigation tab to toggle carrier dispatch view.
  4. Inspect the fee calculation table in DevTools Network tab (GET /api/v1/deals/paperwork).
EXPECTED BEHAVIOR

Tab navigation preserves deal context, active chat filter state, and accurate paperwork total ($42,850.00).

ACTUAL BEHAVIOR

Stale query state parameter clears the deal context, resetting the fee calculation to default ($0.00) and clearing filter.

BUSINESS & FINANCIAL IMPACT

Would have caused dealership sales managers to misquote paperwork during customer checkout. Prevented pre-release.
