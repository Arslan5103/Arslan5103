Befer AI — Embedded Booking Engine & Geofencing

Applying Boundary Value Analysis to geographic radius constraints, cross-origin iframe security testing, and appointment booking lifecycle validation.

01

Project Overview

Befer AI is an intelligent appointment booking and lead acceleration platform designed for field service businesses (HVAC contractors, plumbing professionals, solar installers). The system features embeddable cross-origin booking widgets, real-time calendar slot locking, geospatial distance filtering, and automated outbound telephony dialers.

My role involved authoring end-to-end test specifications, validating geospatial boundary conditions, stress-testing iframe postMessage communications across mobile browsers, and certifying dialer state transitions.

02

The Challenge

Service businesses incur severe financial loss if technicians are dispatched outside their contracted territory. Testing revealed that floating-point mathematical rounding in geospatial queries permitted appointments at 25.04km when the hard threshold was 25.0km.

Additionally, on iOS Safari, cross-origin iframes suppressed ResizeObserver events, causing the embed container to clip at a fixed 320px height and hiding the confirmation CTA button.

03

Test Strategy & Plan

I engineered a multi-tiered test strategy combining black-box boundary testing and API schema validation:

  • Boundary Value Analysis (BVA): Systematically evaluated test points at 24.9km (valid), 25.0km (exact threshold), and 25.1km (invalid out-of-zone) to eliminate rounding errors.
  • Cross-Origin Iframe Testing: Simulated multiple parent host containers with varied Content Security Policies (CSP) and mobile viewports.
  • Concurrency & Race Conditions: Simulated simultaneous attempts to book the same appointment slot to verify ACID database row locking.

05

Automation & Playwright Suite

Automating iframe interactions requires specialized frame locators. I authored robust Playwright suites simulating parent-to-frame interactions:

tests/e2e/befer-booking-iframe.spec.js 
const { test, expect } = require('@playwright/test');

test.describe('Befer AI — Iframe Booking & Slot Locking', () => {
  test('should lock slot and expand container on appointment submission', async ({ page }) => {
    await page.goto('/contractor-demo-embed');

    // Locate cross-domain iframe
    const bookingFrame = page.frameLocator('#befer-booking-frame');

    // Select service and input boundary address
    await bookingFrame.getByRole('combobox', { name: /service/i }).selectOption('HVAC Inspection');
    await bookingFrame.getByPlaceholder('Service Address').fill('Lahore Cantt 24.9km');
    await bookingFrame.getByRole('button', { name: /check availability/i }).click();

    // Pick 10:00 AM slot
    await bookingFrame.getByRole('button', { name: '10:00 AM' }).click();

    // Verify slot lock and confirmation button visibility
    const confirmBtn = bookingFrame.getByRole('button', { name: /confirm appointment/i });
    await expect(confirmBtn).toBeVisible();
    await confirmBtn.click();

    // Assert booking reservation confirmation
    await expect(bookingFrame.getByText('Appointment Confirmed')).toBeVisible();
  });
});

07

Key Learnings & Reflections

Formal test design techniques like Boundary Value Analysis are not merely theoretical textbook exercises; they are the most effective way to detect subtle numerical errors in database queries and mathematical distance algorithms.

Furthermore, cross-origin security sandboxes in mobile Safari behave differently than desktop Chromium. Responsive testing must always incorporate physical device passes.
